# SQL inside strings

Select the SQL inside a string in Python, JavaScript, TypeScript, Java, C#, Go or PHP, or put the cursor in the string, and run Format SQL in String from the right-click menu.

- In a multi-line string (backticks, `"""`, `'''`, `@"..."`) the SQL gets one clause per line.
- In a one-line string it stays on one line, with keyword case and spacing fixed.
